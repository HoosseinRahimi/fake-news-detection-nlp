# Optimizer experiment notebooks

These notebooks are historical experiment snapshots from my NLP/CNN work on the collaborative Fake News Detection project.

| Notebook | Optimizer | Purpose |
|---|---|---|
| `optimizer_experiments/adam.ipynb` | Adam | CNN training and evaluation experiment |
| `optimizer_experiments/adamax.ipynb` | Adamax | Alternative optimizer comparison |
| `optimizer_experiments/sgd.ipynb` | SGD | Gradient-descent optimizer comparison |
| `optimizer_experiments/adadelta.ipynb` | Adadelta | Adaptive optimizer comparison |

## Important notes

- These notebooks were developed interactively in Google Colab and preserve historical outputs.
- Dataset paths must be configured locally before running them.
- The dataset is not included in this repository.
- Results should be treated as experiment records, not as final project benchmarks.
- The integrated team project is available at: https://github.com/hosseindamavandi/Fake-News-Detection
